# 💖 CoupleSync - Same vibes, different places.

**CoupleSync** is a modern, real-time social hangout platform built specifically for couples and close friends. Join a private room with a code, listen to synchronized music, play interactive multiplayer couple games, and chat live with floating romantic reactions!

---

## ✨ Features

- 🎧 **Synchronized Music Player**: Play, pause, seek, and skip tracks together in perfect real-time sync.
- 💬 **Live Chat & Romantic Floating Reactions**: Instant messaging with emoji reactions and tap-to-send floating heart showers on both screens.
- 🎲 **Multiplayer Couple Games**:
  - **Truth or Dare**: Romantic, Fun, Deep, and Spicy categories with turn spinner.
  - **Couple Quiz**: "Who knows who better?" with instant score tracking.
  - **Would You Rather**: Couples dilemmas with live compatibility reveal.
- 🔒 **Private Rooms**: Instant 6-digit room codes (e.g. `LOVE-4821`), copyable invite links, and live presence indicators.
- 📱 **Mobile & Desktop Responsive**: Beautiful dark-mode neon glassmorphism tailored for phones, tablets, and desktop.

---

## 🚀 Getting Started

```bash
# 1. Install all dependencies
npm run install:all

# 2. Start the dev environment (Server on :5000, Client on :3000)
npm run dev
```

Visit **`http://localhost:3000`** in your browser! Open two windows or invite your partner to test real-time synchronization.
